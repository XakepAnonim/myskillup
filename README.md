Репозиторий с практическими заданиями по программированию.

## Структура проекта

### Python

#### 01. Pytest

Практическая работа по установке pytest, управлению зависимостями и тестированию Python-кода.

Файлы:
- `calc.py` - функция сложения двух чисел.
- `test_calc.py` - тест функции сложения.
- `requirements.txt` - зависимости проекта.

Расположение: `python/01_pytest/`

## Запуск тестов

Создание виртуального окружения:

`python -m venv .venv`

Установка зависимостей:

`./.venv/bin/python -m pip install -r python/01_pytest/requirements.txt`

Запуск тестов:

`./.venv/bin/python -m pytest -q python/01_pytest/test_calc.py`

## Среда разработки

- ОС: Manjaro Linux
- Python: 3.14.7
- IDE: PyCharm
- pytest: 9.1.1

### Карта готовности прототипа 414

| Часть | Текущее состояние |
|---|---|
| Добавление и просмотр | Повторяющееся меню, отдельные записи с возрастающими ID и статусом "новая". Название после strip() имеет длину 1–80, приоритет равен только 1/2/3. Одинаковые названия разрешены; неудачное добавление не расходует ID. |
| Поиск, фильтр и статистика | find показывает все совпадения без учёта регистра, filter выбирает новые задачи с приоритетом 2/3, stats показывает количество и уникальные статусы. |
| Время жизни данных | Задачи сохраняются между командами одного процесса. После exit данные теряются, следующий запуск начинается с пустого списка и ID 1. |
| Отложенные возможности | Завершение по ID, удаление, JSON и выделение функций здесь не реализованы. |

Это отдельный учебный прототип с хранением в памяти. Реализация целевого Менеджера, выполнение всех FR/AC и прохождение его TC не заявляются. Целевые документы требований и архитектуры сохранены; учебные команды find/filter/stats сами по себе не подтверждают согласование нового объёма первой версии.
