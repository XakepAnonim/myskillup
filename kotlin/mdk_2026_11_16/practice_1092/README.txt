Файл Practice_1_5_part1.kt содержит несколько независимых задач.
Выберите задачу аргументом запуска от 1 до 6. По умолчанию выполняется задача 1.
Аргумент tests запускает встроенные проверки check.
Пример для уже установленного Kotlin
  kotlinc Practice_1_5_part1.kt -include-runtime -d practice.jar
  java -jar practice.jar 2
  java -jar practice.jar tests
Затем вводите только строки из таблицы выбранной задачи.
Компилятор устанавливать для проверки приложенного отчёта не требуется.
PlaygroundChecks.kt запускается без аргументов в play.kotlinlang.org.
