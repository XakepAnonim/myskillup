Контракт решения
average_mark принимает три числовые оценки и возвращает их среднее без округления. Внешний запуск читает ровно три числа через пробел с точкой для дробной части и печатает round(..., 2), как в таблице. Поведение для иных форм ввода условием не установлено и в этом решении не расширяется.

Найденные причины и исправление
Исходная операция a + b + c / 3 делит только третью оценку. Скобки в (first_mark + second_mark + third_mark) / 3 обеспечивают деление всей суммы. Исходный комментарий сохранён в исправленном файле.

def average_mark(first_mark: float, second_mark: float, third_mark: float) -> float:
    return (first_mark + second_mark + third_mark) / 3  # average_mark(5, 5, 5) должно быть 5.0


def test_average_identical_marks() -> None:
    assert average_mark(5, 5, 5) == 5.0


def test_average_different_marks() -> None:
    assert average_mark(5, 4, 3) == 4.0


def test_average_fractional_result() -> None:
    assert round(average_mark(2, 2, 3), 2) == 2.33


if __name__ == "__main__":
