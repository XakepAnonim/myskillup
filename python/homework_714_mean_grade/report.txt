Контракт решения
mean_grade принимает строку целых оценок с пробельными разделителями и возвращает float, округлённый round(..., 2). Пустая строка или только пробелы дают 0.0. Диапазон 2–5 и ответ на нечисловые оценки здесь не заданы. Внешний запуск печатает результат функции, а не строку из двух фиксированных десятичных знаков.

Найденные причины и исправление
Исходное // отбрасывает дробную часть среднего, поэтому заменено на /. Отдельная ветка для пустого списка оценок возвращает 0.0 до деления и устраняет ZeroDivisionError. Это другой контракт, чем редактор 714/3290, который возвращает строку и иначе обрабатывает пустой ввод.

Итоговый код
```python
def mean_grade(grades_text: str) -> float:
    grades = list(map(int, grades_text.split()))
    if not grades:
        return 0.0
    return round(sum(grades) / len(grades), 2)


def test_mean_identical_marks() -> None:
    assert mean_grade("5 5") == 5.0


def test_mean_fractional_result() -> None:
    assert mean_grade("5 4") == 4.5


def test_mean_rounding() -> None:
    assert mean_grade("5 4 4") == 4.33


def test_mean_empty_text() -> None:
    assert mean_grade("") == 0.0


def test_mean_whitespace_separators() -> None:
    assert mean_grade(" 5  4\t4 ") == 4.33


def test_mean_single_mark() -> None:
    assert mean_grade("3") == 3.0


if __name__ == "__main__":
    print(mean_grade(input()))
```
