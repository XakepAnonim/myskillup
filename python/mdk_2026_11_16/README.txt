по шесть программ, принятых SkillUp по 100/100. В корневом каталоге

Оценки сверены после повторного открытия итогов каждого урока.

Уроки 987 и 1044 содержат одинаковые условия и заготовки для разных групп.
Задания 988 и 1034 совпадают с прежними практикумами 865 и 873;
условия проверены перед использованием прежних решений. Исходники
ранее выполненных работ не редактировались.

Новые программы содержат функции логики, docstring с контрактом,
тест-функции и отдельную main(). Для темы doctest добавлены рабочие
примеры вызова и исключений. Тесты не засоряют вывод программы.

Устаревший пример normalize_phone_old действительно не прошёл doctest.
Фактическое падение сохранено в old-doctest-failure.txt рядом с шагами
3999 и 4153. Этот старый пример помечен SKIP в общем запуске doctest,
чтобы намеренно ошибочный образец не печатал лишние строки при сдаче.
Проверки исправленной normalize_phone и реальный вызов passes(old)
сохраняются и выполняются. Ожидаемое падение не выдано за успешный тест.

Локальная проверка итоговых 33 программ выполнена Python 3.14.7.
Прошли 264 отдельных запуска со сравнением stdout, stderr и кода
завершения, 33 тест-функции и 81 рабочий пример doctest.
Календарная функция дополнительно сверена с datetime.date в 1697 случаях.
Синтаксис каждого публикуемого .py проверен с грамматикой Python 3.8;
локальный запуск Python 3.8 не заявляется.
